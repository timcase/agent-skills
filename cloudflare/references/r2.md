# Cloudflare R2 API Reference

Base URL: `https://api.cloudflare.com/client/v4`
Auth header: `Authorization: Bearer $CLOUDFLARE_API_TOKEN`

> This covers R2's **management plane** (buckets, lifecycle, CORS, domains,
> notifications, lock, metrics, sippy). For uploading, downloading, or
> listing actual object contents, use the **s3cmd skill** against R2's
> S3-compatible endpoint instead of curl — see "Object I/O" below.

---

## Find Account ID

```bash
curl -s "https://api.cloudflare.com/client/v4/accounts" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" | jq -r '.result[] | {id, name}'
```

Save the returned string as `ACCOUNT_ID`. All endpoints below are scoped
under `/accounts/$ACCOUNT_ID/r2/...`.

---

## Buckets

**List:**
```bash
curl -s "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/r2/buckets" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" | jq '.result.buckets[] | {name, creation_date}'
```

**Get one:**
```bash
curl -s "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/r2/buckets/$BUCKET_NAME" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

**Create:**
```bash
curl -s -X POST "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/r2/buckets" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  -H "Content-Type: application/json" \
  --data '{ "name": "my-bucket", "locationHint": "enam" }'
```
`locationHint` is optional (e.g. `wnam`, `enam`, `weur`, `eeur`, `apac`).

**Patch (e.g. change storage class):**
```bash
curl -s -X PATCH "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/r2/buckets/$BUCKET_NAME" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  -H "Content-Type: application/json" \
  --data '{ "storageClass": "InfrequentAccess" }'
```

**Delete:**
```bash
curl -s -X DELETE "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/r2/buckets/$BUCKET_NAME" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```
Bucket must be empty before it can be deleted.

## Lifecycle Rules

**Get:**
```bash
curl -s "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/r2/buckets/$BUCKET_NAME/lifecycle" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

**Put:**
```bash
curl -s -X PUT "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/r2/buckets/$BUCKET_NAME/lifecycle" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  -H "Content-Type: application/json" \
  --data '{
    "rules": [
      {
        "id": "expire-old-logs",
        "enabled": true,
        "conditions": { "prefix": "logs/" },
        "deleteObjectsTransition": { "condition": { "type": "Age", "maxAge": 2592000 } }
      }
    ]
  }'
```
`maxAge` is in seconds. `PUT` replaces the whole rule set.

## Custom Domains

**List:**
```bash
curl -s "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/r2/buckets/$BUCKET_NAME/domains/custom" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

**Get settings for one domain:**
```bash
curl -s "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/r2/buckets/$BUCKET_NAME/domains/custom/$DOMAIN" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

**Attach:**
```bash
curl -s -X POST "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/r2/buckets/$BUCKET_NAME/domains/custom" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  -H "Content-Type: application/json" \
  --data '{ "domain": "assets.example.com", "enabled": true, "zoneId": "$ZONE_ID" }'
```
The domain must already exist in a zone on this account (see `dns.md` to
find `ZONE_ID`) — attaching creates the CNAME automatically.

**Configure (e.g. toggle enabled):**
```bash
curl -s -X PUT "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/r2/buckets/$BUCKET_NAME/domains/custom/$DOMAIN" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  -H "Content-Type: application/json" \
  --data '{ "enabled": false }'
```

**Remove:**
```bash
curl -s -X DELETE "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/r2/buckets/$BUCKET_NAME/domains/custom/$DOMAIN" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

## Event Notifications

Rules are keyed by the destination Queue ID.

**List rules:**
```bash
curl -s "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/event_notifications/r2/$BUCKET_NAME/configuration" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

**Get one rule:**
```bash
curl -s "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/event_notifications/r2/$BUCKET_NAME/configuration/queues/$QUEUE_ID" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

**Create/replace a rule:**
```bash
curl -s -X PUT "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/event_notifications/r2/$BUCKET_NAME/configuration/queues/$QUEUE_ID" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  -H "Content-Type: application/json" \
  --data '{
    "rules": [
      { "actions": ["PutObject", "DeleteObject"], "prefix": "uploads/" }
    ]
  }'
```

**Delete a rule:**
```bash
curl -s -X DELETE "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/event_notifications/r2/$BUCKET_NAME/configuration/queues/$QUEUE_ID" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

## Sippy (Incremental Migration from S3/GCS)

**Get config:**
```bash
curl -s "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/r2/buckets/$BUCKET_NAME/sippy" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

**Enable (example: migrating from AWS S3):**
```bash
curl -s -X PUT "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/r2/buckets/$BUCKET_NAME/sippy" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  -H "Content-Type: application/json" \
  --data '{
    "source": {
      "provider": "aws",
      "bucket": "source-bucket",
      "region": "us-east-1",
      "accessKeyId": "AKIA...",
      "secretAccessKey": "..."
    },
    "destination": { "accessKeyId": "...", "secretAccessKey": "..." }
  }'
```

**Disable:**
```bash
curl -s -X DELETE "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/r2/buckets/$BUCKET_NAME/sippy" \
  -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

## Object I/O (upload / download / list contents)

Don't use the Cloudflare v4 API for this — R2's object PUT/GET here is
capped at 300MB with no multipart support. Instead configure R2 as an
S3-compatible provider and use the **s3cmd skill**:

```bash
s3cmd -c ~/.s3cfg-r2 ls s3://$BUCKET_NAME/
s3cmd -c ~/.s3cfg-r2 put localfile.txt s3://$BUCKET_NAME/path/file.txt
s3cmd -c ~/.s3cfg-r2 get s3://$BUCKET_NAME/path/file.txt localfile.txt
```

See `s3cmd/references/providers.md` for the R2 config profile (endpoint,
access keys, region).

## Response shape

Success:
```json
{ "success": true, "result": { ... } }
```

Error:
```json
{ "success": false, "errors": [{ "code": 10006, "message": "The bucket does not exist." }] }
```

Always check `success` before treating the result as valid.
